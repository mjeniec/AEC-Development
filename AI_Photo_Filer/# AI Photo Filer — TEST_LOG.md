## Commit Message

Implement local face detection and initial facial recognition workflow using YuNet and SFace

---

## Change Made

Developed the initial prototype of the AI Photo Filer using Python, OpenCV and pretrained AI models.

The application now:

- Searches a specified directory for image files.
- Identifies file extensions and extracts image dimensions.
- Detects faces using the YuNet AI model.
- Retrieves bounding-box coordinates for detected faces.
- Draws rectangles around detected faces for visual debugging.
- Saves annotated images to a separate output folder.
- Uses the SFace model to generate numerical facial embeddings.
- Introduces a local SQLite database for storing information about known individuals.

The application operates locally without external AI services.

---

## Reason for Change

To develop a locally running application capable of automatically identifying individuals and organising family photographs and videos.

The initial prototype also provides practical experience with:

- Python programming and file management.
- Computer vision using OpenCV.
- Using pretrained AI models.
- Understanding facial detection versus facial recognition.
- Generating and comparing numerical embeddings.
- Local database management using SQLite.

## Current Limitations

- Reliable identification of individuals is not yet implemented.
- Facial embeddings are generated but not yet fully integrated with the identity database.
- Similarity thresholds have not been established.
- Automatic photograph organisation has not been implemented.
- Video processing is not yet supported.
- No graphical interface is available.
- Recognition accuracy requires further testing.

---

## Next Change / Hypothesis

Implement facial embedding comparison and identity matching.

The next version should:

- Compare embeddings generated by SFace.
- Calculate similarity between detected faces.
